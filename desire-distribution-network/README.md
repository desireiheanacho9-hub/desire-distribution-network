# DESIRE DISTRIBUTION NETWORK — Smart Mirror Website

Updated responsive 3D corporate website based on the approved DESIRE Distribution Network visual direction and the Mirroh.AI Product Catalogue 2026.

## Three flagship solution categories
1. **Fashion Virtual Try-On / DESIRE Fashion Studio** — proposed custom full-length fashion mirror and software platform for tailors, boutiques and homeowners. The Mirroh catalogue's F43 (43-inch) and Custom Series (page 18) are shown as hardware candidates only. Real-time fashion try-on, camera integration and processing capability are not confirmed by the catalogue.
2. **AI Hospitality Smart Mirrors** — catalogue references include M2G, M2S, M2H and 19-inch Mirror TV.
3. **Residential AI Smart Mirrors** — catalogue references include LOONA, K1, Mini133, PAD133, PAD133-II, C07, X3, M2K, M2D, S2 and D1.

The catalogue gallery includes model imagery and page references from the 18-page Mirroh.AI 2026 catalogue. The S2 and M2D remain in the personal beauty catalogue group and are not described as fashion virtual try-on hardware.

## Features
- React + Vite + Three.js + React Three Fiber interactive 3D showroom.
- Navy, white and subtle-gold visual identity.
- Three flagship solution selector.
- Filterable Mirroh.AI catalogue with model images, model sizes and catalogue page references.
- Responsive layouts for desktop, tablet and mobile.
- WhatsApp wholesale/project enquiry links for +234 702 644 5594.
- Clear distinction between supplier-catalogue hardware and proposed DESIRE software features.

## Run locally
Requires Node.js 20 or newer (Node 22 recommended).

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
Vite output directory: `dist`.

## Deploy to Vercel
Import the project/repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
