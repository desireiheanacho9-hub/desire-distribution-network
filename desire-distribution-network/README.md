# Desire Distribution Network

Premium responsive smart-mirror distributor website built with React, Vite, Three.js and React Three Fiber.

## Included
- Interactive 3D showroom for Fashion, Hospitality and Residential smart mirror concepts.
- Responsive layout for mobile, tablet and desktop.
- Product category selector and WhatsApp wholesale enquiry links for +234 702 644 5594.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
Import this repository at https://vercel.com/new. Framework: Vite; build command: `npm run build`; output directory: `dist`.
