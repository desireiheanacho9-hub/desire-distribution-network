# DESIRE DISTRIBUTION NETWORK — Luxe Edition

A React + Vite + Three.js smart-mirror distribution website for DESIRE DISTRIBUTION NETWORK.

## Product architecture

The website presents three flagship categories:

1. **Fashion Virtual Try-On** — a DESIRE software concept for tailors, boutiques and homeowners. The Mirroh.AI F43 (page 13) and Custom Series (page 18) are presented only as potential hardware foundations. Fashion camera support, processing capability and live garment rendering are not confirmed by the catalogue.
2. **AI Hospitality Smart Mirrors** — catalogue hardware options for hotels, shortlets and serviced apartments.
3. **Residential AI Smart Mirrors** — catalogue hardware options for modern homes.

The product catalogue is based on the 18-page Mirroh.AI 2026 catalogue supplied to DDN. Product capabilities and specifications must be confirmed by Mirroh.AI.

## Design update — Luxe Edition

- Preserves the approved dark navy and champagne-gold identity.
- Adds a more editorial luxury feel with Cormorant Garamond display typography, metallic gold accents, richer lighting and refined hover states.
- Uses the actual full-length fashion mirror application shown on catalogue page 18 for the Fashion Studio visuals.
- Improves catalogue cards, solution panels, buttons and wholesale call-to-action styling.
- Keeps the existing React Three Fiber 3D showroom and responsive layouts.
